This needs IFS configuration first

Enabling access only lets the extension run on this site. It stores its notes in IFS, so the environment must already have:

  • the CStickyNotes custom entity — normally imported from the Application Configuration Package supplied with the extension
  • a Custom Event on CStickyNotes with an E-Mail action, if you want @-mention notifications to actually send
  • your user granted access to the CStickyNotes projection

If the package hasn’t been imported, notes will not save. The check below tells you either way.

No data leaves your IFS environment

Chrome is about to ask to “read and change your data” on this site. That is the only permission that lets an extension draw notes on the page, and Chrome words it the same way for every extension.

What this one actually does with it: notes are written to CStickyNotes in your own IFS tenant, and people are looked up through your own IFS person list. There is no server behind this extension, no analytics, no telemetry, and no other network call of any kind.
