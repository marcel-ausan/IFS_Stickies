Notes that live on the record.

Pin a note to a customer order, a work order, a part — anything with its own page in IFS Cloud. Everyone on your team who opens that record sees it, and every note is stored in your own IFS environment. No server, no third party, nothing to host.

What it is

A browser extension that restores the post-it note feature IFS Applications had and IFS Cloud does not — notes attached to a specific record, visible to whoever opens it.

  • Draggable, resizable notes in eight colours, scoped to the record on screen.
  • Type @ to mention a colleague — the search matches both full name and FND user id.
  • Press ✉ Notify and they get an e-mail with a link straight back to the record.
  • Sent by your own IFS, from your own mail configuration.

Where the data lives

In your IFS environment, in a custom entity the supplied configuration package creates. There is no backend behind this extension — no server to host, no account to create, no data leaving your tenant. That is usually the difference between a security review that passes and one that stalls.

Getting it

Two pieces: the browser extension, and a small Application Configuration Package your IFS administrator imports once per environment. Both are in the repository, and both are free.

  • The repository — extension source, the configuration package under deploy/, and full setup notes.
  • The extension opens its own setup guide on install, including an administrator page that can be printed or copied into a ticket.

Support

The software is MIT licensed and offered as is, with no warranty. That is not boilerplate: it depends on Aurena’s URL scheme and on the REST naming IFS generates for a custom logical unit, neither of which is a documented interface, and an IFS upgrade can move either.

Implementation and support services are available from the developer — environment setup, configuration for your own IFS instance, browser rollout, and keeping it working across IFS releases. Get in touch if you would rather not carry that yourself.
